# shikisai2

iOSアプリ「色彩検定2級対策(非公式)」の公開情報(サポート・プライバシーポリシー・利用規約)を管理するリポジトリです。GitHub Pages(`main` ブランチの `/docs`)で公開しています。

- サポート: https://taaaaho.github.io/shikisai2/
- プライバシーポリシー: https://taaaaho.github.io/shikisai2/privacy.html
- 利用規約: https://taaaaho.github.io/shikisai2/terms.html

ページの元ファイルは非公開リポジトリ(`shikisai2-code`)の `docs/` にあります。編集したらこのリポジトリの `docs/` にも同じファイルを反映してください。

本アプリは個人開発の非公式アプリであり、一般社団法人色彩検定協会(AFT)とは提携・協力・監修関係はありません。「色彩検定」は一般社団法人色彩検定協会の登録商標です。
